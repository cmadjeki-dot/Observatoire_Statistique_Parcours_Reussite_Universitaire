# Publication GitHub

Les sources sont publiées sur `main` dans le [dépôt confirmé](https://github.com/cmadjeki-dot/Observatoire_Statistique_Parcours_Reussite_Universitaire). Le [site public](https://cmadjeki-dot.github.io/Observatoire_Statistique_Parcours_Reussite_Universitaire/) est servi par GitHub Pages depuis `gh-pages`. Les fichiers `data/`, `outputs/`, bibliothèques renv, caches et PBIX restent ignorés. Aucune licence de réutilisation n’a été ajoutée automatiquement.

La publication inclut les méthodes, fonctions R, tests, questionnaires fictifs, sources Quarto, tableaux web et Shiny, et projet Power BI PBIP. Seuls les agrégats protégés sont publiés. Les rapports HTML/PDF et archives sélectionnées figurent sur le site ; aucune table individuelle n’est fournie. Le premier commit vérifié est `c578e854065a966f03f85acef087166a13bebc15`.

Avant tout nouvel envoi, exécuter `python scripts/audit_publication.py`, examiner `git status --short` et les modifications. Les historiques imbriqués sont sauvegardés localement dans `outputs/backups/nested_git/` ; leurs fichiers sont désormais suivis normalement par le dépôt principal. Les métadonnées `.openai`, caches et secrets sont exclus. Les espaces de fin du script généré `renv/activate.R` et le saut de ligne Markdown de la note sont conservés ; les autres sources passent `git diff --check`.

Cette CI ne valide ni le canvas Desktop ni l’import LimeSurvey.

Pour actualiser le site : reconstruire les rapports, PDF et ressources selon [le guide](18_site_quarto.md), puis exécuter `scripts/publish_pages.ps1`. Ce script envoie le site rendu sur `gh-pages`, sans envoi forcé. Vérifier ensuite le déploiement et les liens publics. Les preuves structurées sont conservées dans [26_publication_github.json](26_publication_github.json).
